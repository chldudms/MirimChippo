# MirimChippo
플레이어가 미림의 학생이 되어 취업을 성공하면 클리어 하게되는 액션게임 (it쇼)
![image](https://github.com/user-attachments/assets/2e7a3797-bfdb-49a7-b7cc-c5d6f9ae7c55)

<br>게임: https://play.unity.com/en/games/c0094566-319e-4efc-b435-cfb9f817b431/mirimchippo </br>

미림취뽀는 미림마이스터고 학생들이 학교에
입학하고 나서 취업까지 성공하는 루트를
게임으로 재미있게 풀어냈습니다. 
취업을 하는 과정이 쉽지는 않지만 
그럼에도 학생들이 끊임없이 도전하고 성장해
나가는 모습을 게임 속 여정에 녹여냈습니다.

‘취업’이라는 현실적인 목표를 향해 달려가는 미림마이스터고 학생들의 여정을
게임이라는 친근하고 재미있는 형식으로 재구성하여,
학생들이 겪는 고민, 도전, 성장 과정을 자연스럽게 공감하고 이해할 수 있도록 기획하였습니다.
